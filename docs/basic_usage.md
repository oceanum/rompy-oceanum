# Basic Usage

This guide shows how to use the `rompy-oceanum` package through the Oceanum CLI to submit rompy model runs to Oceanum's Prax system.

## Quick Start Workflow

### Step 1: Authentication Setup

First, authenticate with Oceanum (this replaces manual token management):

```bash
rompy rompy oceanum-auth login
```

Set your project environment variables:

```bash
export PRAX_ORG="your_organization"
export PRAX_PROJECT="your_project"
```

### Step 2: Generate Configuration

Generate a rompy configuration optimized for Prax execution:

```bash
oceanum rompy init swan --template basic
```

This creates a file named `rompy_config_swan_basic.yml` with all necessary components for Prax execution.

### Step 3: Submit to Prax Pipeline

Execute your configuration via Prax:

```bash
oceanum rompy run rompy_config_swan_basic.yml swan --pipeline-name swan-from-rompy
```

If the pipeline doesn't exist, you'll get helpful guidance on available options.

### Step 4: Monitor Execution

Monitor your pipeline run:

```bash
oceanum rompy status <run-id>
```

View real-time logs:

```bash
oceanum rompy logs <run-id> --follow
```

### Step 5: Retrieve Results

Download organized outputs:

```bash
oceanum rompy sync <run-id> ./outputs --organize
```

## Pipeline Discovery

List available pipelines in your project:

```bash
oceanum rompy run --list-pipelines
```

Common pipeline names for SWAN models:
- `swan-from-rompy`
- `swan-rompy-basic` 
- `swan-rompy-operational`

## Using the Python API

You can also use the Python API for programmatic access:

```python
import rompy
import rompy_oceanum  # Import to activate the pipeline backend

# Create a rompy model configuration
model_run = rompy.ModelRun(
    run_id="my_run",
    output_dir="./outputs",
    period={
        "start": "20230101T000000",
        "duration": "1d", 
        "interval": "1h"
    },
    config={
        "model_type": "swanconfig",
        # ... rest of your SWAN configuration ...
    }
)

# Execute via Prax pipeline backend
result = model_run.pipeline(
    backend="prax",
    pipeline_name="swan-from-rompy",
    # org and project come from environment variables
    stage="dev",
    wait_for_completion=True,
    download_outputs=True
)

print(f"Run ID: {result.prax_run_id}")
print(f"Status: {result.status}")
```

## Configuration Templates

Generate different types of configurations:

```bash
# Basic SWAN configuration
oceanum rompy init swan --template basic

# Operational SWAN configuration  
oceanum rompy init swan --template operational

# Interactive setup
oceanum rompy init swan --template basic --interactive

# Custom domain and parameters
oceanum rompy init swan --template basic \
  --domain "north_sea" \
  --bbox "2.0,51.0,8.0,56.0" \
  --grid-resolution 0.05
```

## Error Handling

If you encounter issues:

### File Not Found
```bash
❌ Error parsing configuration: ...
💡 Make sure your configuration file exists and contains valid YAML or JSON
📁 Looking for: config.yml
```

**Solution**: Use the correct filename generated by `oceanum rompy init`, e.g., `rompy_config_swan_basic.yml`

### Pipeline Not Found
```bash
❌ Pipeline 'my-pipeline' not found
💡 Try one of these options:
   1. List available pipelines: oceanum rompy run --list-pipelines
   2. Deploy pipeline first: oceanum rompy run config.yml swan --pipeline-name my-pipeline --deploy --template <template_file>
   3. Use existing pipeline name from step 1
```

**Solution**: Either use an existing pipeline name or deploy a new one using a template.

First, discover available pipelines:
```bash
oceanum rompy run --list-pipelines
```

## Advanced Features

### Pipeline Discovery
```bash
# List all available pipelines
oceanum rompy run --list-pipelines

# Then use a discovered pipeline name
oceanum rompy run rompy_config_swan_basic.yml swan --pipeline-name <discovered-name>
```

### Wait for Completion and Download
```bash
oceanum rompy run rompy_config_swan_basic.yml swan --pipeline-name my-pipeline \
  --wait --timeout 3600 --download --output-dir ./results
```

### Deploy Pipeline from Template
```bash
oceanum rompy run rompy_config_swan_basic.yml swan --pipeline-name my-new-pipeline \
  --deploy --template ./pipeline-template.yaml
```

### Organized Output Downloads
```bash
oceanum rompy sync <run-id> ./outputs --organize --zip
```

This creates organized directories by stage and file type, with optional zip compression.
